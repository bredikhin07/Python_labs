# Лабораторные работы по Python

Материалы по курсу «Парадигмы и конструкции языков программирования».

- `lab_1` — лабораторная работа №1: программа и отчёт.
- `lab_2` — лабораторная работа №2: программа, пакет с классами, тесты, список зависимостей и отчёт.
- `lab_3-4` — лабораторная работа №3–4: семь задач в пакете `lab_python_fp`, исходные данные, результат запуска и отчёт. Порядок запуска описан в `lab_3-4/README.md`.

Виртуальное окружение и кеш Python создаются на конкретном компьютере и в репозиторий не включены.
