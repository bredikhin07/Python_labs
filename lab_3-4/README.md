# Лабораторная работа №3–4

Решения семи задач находятся в пакете `lab_python_fp`. Для каждой задачи создан отдельный файл. Использованы генераторы, итератор, `*args`, `**kwargs`, `sorted`, `filter`, `map`, `zip`, декоратор и два способа создания контекстного менеджера.

Из папки `lab3-4` каждый файл можно запустить отдельно, например:

```bash
python3 lab_python_fp/field.py
python3 lab_python_fp/unique.py
python3 lab_python_fp/process_data.py data_light.json
```

Остальные задачи запускаются так же: `gen_random.py`, `sort.py`, `print_result.py`, `cm_timer.py`.

Файл `data_light.json` взят по [ссылке из задания](https://github.com/ugapanyuk/BKIT_2021/blob/main/notebooks/fp/files/data_light.json). В нём 4 635 вакансий. При проверке цепочки обработки получено 2 266 уникальных названий и 9 профессий, начинающихся со слова «программист». Числа зарплат и время выполнения меняются при каждом запуске.

В комментариях шаблона `Unique` значение `ignore_case` описано противоположно основному условию и примерам. Реализация следует условию и примерам: при `ignore_case=True` строки в разном регистре считаются одинаковыми.
